REQUISITOS DE LA ACTIVIDAD

La práctica

Una práctica individual para conectar diseño, maquetación y experiencia de usuario a partir de un hotel real.

  1. 01
    FigmaDiseño
  2. 02
    BootstrapDesarrollo
  3. 03
    PublicaciónWeb en línea

  1. InicioPresentación del hotel y buscador visual de reservas.
  2. HabitacionesCatálogo con imágenes, características y precios.
  3. DisponibilidadResultados simulados y selección de habitación.
  4. Completar reservaResumen, datos personales y pago simulado.
  5. ContactoDirección, teléfono, correo y ubicación. Puede integrarse en otra vista.

Prototipo de alta fidelidad en Figma, metodología Mobile First y maquetación con la rejilla, los breakpoints y los componentes de Bootstrap 5. Identidad visual coherente, CSS propio y navegación funcional. No se utilizan plantillas prediseñadas.

Publicación en un hosting gratuito con URL pública. Comprobación de páginas, enlaces, recursos y adaptación a distintos dispositivos. En clase se presenta el hotel, el prototipo, la web, la simulación de reserva, los componentes utilizados y las dificultades resueltas.

Las habitaciones disponibles y los precios totales pueden utilizar datos de ejemplo. No se realizan reservas ni pagos reales y no se solicitan ni almacenan datos bancarios auténticos.

Esta revisión es personal y no envía datos a Moodle ni al docente. Sin el guardado activo, las marcas solo duran esta visita.

    Maquetación y componentes

    • Rejilla Bootstrap 5
      Una columna en móvil, dos desde 768 px y tres desde 992 px para los proyectos.
    • Espaciado
      Separación de 24 px entre tarjetas; márgenes y rellenos mediante utilidades de Bootstrap.
    • Componentes
      Navbar, Collapse, Cards, Buttons, Button group, Forms, Switch, Accordion, Table, List group, Toast, Progress y ScrollSpy, junto con el desplegable nativo details.
    • Acabados y accesibilidad
      Esquinas de 4–6 px, bordes finos y foco visible. Contraste adaptado a cada tema. Transición de 180 ms al filtrar y confirmación de copia durante 1,8 s. Las animaciones se omiten si el dispositivo solicita reducir el movimiento.
